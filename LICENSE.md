# Lisens

Repoet inneholder to slags innhold, med hver sin lisens.

## Data og dokumentasjon: NLOD 2.0

Alt i `data/` og `docs/`, og README og BIDRA, er gjort tilgjengelig under **Norsk lisens for
offentlige data (NLOD) 2.0**: <https://data.norge.no/nlod/no/2.0>

Innholdet kan fritt kopieres, brukes og bearbeides, også kommersielt, så lenge kilden oppgis.
Den rettslig bindende teksten er den som ligger på lenken over.

Oppgi kilden slik:

> Inneholder data fra Oslo kommunes innbyggerundersøkelse (Oslo kommune), under NLOD 2.0.
